# Test layout

- `unit/`: deterministic scoring, rules, baselines, feature extraction, and travel calculations.
- `integration/`: SQLite repositories, migrations, model adapters, and service boundaries.
- `scenarios/`: end-to-end compromised-account and insider-threat stories with exact reason codes.
- `fixtures/`: shared test-only event data.

Every implementation task should add the narrowest relevant test and run the affected suite.
